## Overview

TurnoverFlow is a short-term rental turnover management system designed to help property managers and rental operators organize the work required between guest stays.

Instead of managing cleaners, property tasks, supplies, inspections, and turnover deadlines across separate notes or spreadsheets, TurnoverFlow brings the workflow together in one application.

The system is built with React and uses a local-first architecture, allowing it to run without requiring a server or paid backend service to get started.

## Turnover Management

TurnoverFlow helps organize the complete process between guest stays.

Property managers can track upcoming turnovers, assign and coordinate cleaners, monitor checklist completion, review issues, manage supplies, and keep guest-ready deadlines visible from one system.

---

## Calendar & Scheduling

The turnover calendar provides a centralized view of scheduled property turnovers and operational deadlines.

Users can quickly review upcoming work and navigate between properties, cleaners, checklists, supplies, issues, and other operational areas.

---

## Cleaner Workflow

TurnoverFlow includes cleaner-focused workflows for managing assigned turnover work and associated cleaning tasks.

This helps separate operational management from the cleaner's day-to-day workflow while keeping turnover information organized in the same application.

## Local-First Architecture

TurnoverFlow V1.0.0 is designed as a local-first application.

That means:

- No server is required to get started
- No paid backend service is required
- No cloud account is required for basic operation
- Application data is stored locally
- Backup and data-management tools are included

This makes the system easy to run, evaluate, customize, and extend.
